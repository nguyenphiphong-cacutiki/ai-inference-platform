# --- OCR engine ---
# RapidOCR runs the PP-OCR (PaddleOCR) model family via ONNX Runtime instead of
# the paddlepaddle native runtime. Same models, but a pure-ONNX backend that is
# far more stable in slim containers (the paddlepaddle wheel aborts with
# "free(): invalid size" on recent glibc). Models ship inside the wheel, so the
# service runs fully offline with no download at startup.
